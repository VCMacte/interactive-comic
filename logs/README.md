# Журналы с телефона

Сюда кладутся файлы, выгруженные кнопкой «Выгрузить журнал» на главном
экране приложения. Разбор:

```
node tools/log-report.mjs logs/comic-log-2026-10-18-20-11-05.json
```

Сами файлы в репозиторий не попадают (`.gitignore`): в них имя устройства,
версия браузера и время, когда ребёнок играл. Папка и этот файл остаются,
чтобы путь из команды существовал.

Что внутри и зачем — в `CLAUDE.md`, раздел «Журнал событий».
